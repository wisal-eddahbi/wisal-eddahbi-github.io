# Portfoli personal de Wisal Eddahbi

Web personal creada a partir de la plantilla Laura de BootstrapMade i adaptada amb informació pròpia.

## Pàgines
- `index.html`: inici
- `sobre-mi.html`: presentació i formació
- `habilitats.html`: coneixements
- `projectes.html`: projectes, taula i galeria
- `contacte.html`: dades de contacte i formulari demostratiu

## Accés
Obre `index.html` amb un navegador web.

## Publicació
El projecte es pot publicar a GitHub Pages pujant tots els fitxers del directori.

## Plantilla
Laura - BootstrapMade: https://bootstrapmade.com/laura-free-creative-bootstrap-theme/
